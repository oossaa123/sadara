# 🏫 موقع كلية الصدارة للعلوم الطبية والتقنية

موقع ويب فائق الاحترافية وتفاعلي تم بناؤه خصيصاً لجذب الطلاب وتسهيل عملية التسجيل والالتحاق بالكلية. يتميز الموقع بتصميمه العصري المتجاوب ودعمه الكامل للتأثيرات البصرية المتقدمة والوضع الليلي.

---

## 🎨 الهوية البصرية والتصميم

- **اللون الأساسي**: الأرجواني الملكي (`#8A2E76`) - يعبر عن الفخامة والعمق الأكاديمي.
- **اللون الثانوي**: الذهبي (`#D4AF37`) - يعبر عن التميز والريادة والصدارة.
- **الخلفيات**: تباين متوازن بين الأبيض والأسود المطفأ مع درجات خفيفة مريحة للعين.
- **الخطوط**: خطوط عربية فاخرة (Cairo لعناوين بارزة، وTajawal للنصوص الطويلة).
- **التصميم العام**: يعتمد على تأثير الزجاج المطفأ (Glassmorphism) مع هوامش مريحة للعين وتجاوب كامل مع مختلف مقاسات الشاشات (الهواتف، الأجهزة اللوحية، أجهزة الكمبيوتر).

## ✨ أهم الميزات التفاعلية المدمجة

1. **الوضع الداكن والفاتح (Dark/Light Mode)**: تبديل سلس للثيم مع حفظ رغبة المستخدم تلقائياً في المتصفح.
2. **عداد إحصائي تفاعلي (Animated Counter)**: أرقام إحصاءات الطلاب والمعامل تتصاعد بشكل حركي عند التمرير إليها.
3. **تبويبات الأقسام (Interactive Tabs)**: تبديل سلس وجميل بين التخصصات الطبية والتخصصات التقنية/الإدارية.
4. **عداد تنازلي ذكي (Urgency Countdown)**: يخلق شعوراً بالسرعة لدى الطلاب لحجز مقاعدهم والاستفادة من خصومات التسجيل المبكر.
5. **كاروسيل شهادات الطلاب (Testimonials Carousel)**: يعرض قصص نجاح الخريجين بحركة تلقائية وتفاعلية تدعم التمرير اليدوي.
6. **نموذج التسجيل السريع (Quick Admission Form)**: نموذج منظم ذو تصميم زجاجي أنيق مع التحقق من الحقول لتسهيل عملية التواصل وجلب العملاء.
7. **زر واتساب العائم**: أيقونة عائمة تمكن الطلاب من مراسلة الكلية بضغطة زر واحدة مع رسالة ترحيبية معدة مسبقاً.

## 🚀 كيفية تشغيل الموقع

الموقع تم تصميمه ليكون خفيفاً وسريعاً جداً ولا يحتاج إلى خادم معقد. يمكنك تشغيله بعدة طرق:

### 1. التشغيل المباشر

فقط قم بفتح ملف `index.html` في أي متصفح ويب (Chrome, Firefox, Safari, Edge) وسيفتح الموقع مباشرة بكامل ميزاته.

### 2. التشغيل باستخدام خادم محلي (نوصي به للتأثيرات)

إذا كنت تستخدم Visual Studio Code، يمكنك تثبيت إضافة **Live Server** والضغط على **Go Live**.
أو عبر منفذ الأوامر في مجلد المشروع:

```bash
# باستخدام Python
python3 -m http.server 8000

# أو باستخدام Node.js
npx serve .
```

ثم افتح الرابط: `http://localhost:8000` أو `http://localhost:3000`.
